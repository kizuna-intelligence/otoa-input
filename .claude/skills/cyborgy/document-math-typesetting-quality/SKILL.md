# 数式は TeX と同等の品質で組む

文書に数式を書くときは、**TeX で組んだのと同等の品質**にする。

本文の文字を並べた擬似数式で済ませない。次はいずれも不可。

```
x^2 + y^2 = z^2        sum_{i=1}^{n} a_i        (a+b)/(c+d)
sqrt(x)                E[X]  を E[X] として本文フォントで組む
```

## 守ること

### 字形

- 変数・未知数は**イタリック**。$x$, $n$, $\theta$
- 関数名・演算子名は**ローマン体**。$\sin$, $\log$, $\max$, $\arg\max$, $\mathrm{d}x$
- ベクトル・行列は太字または太字イタリックで、文書内で統一する
- 単位はローマン体で、数値との間に細いアキを入れる。$5\,\mathrm{ms}$
- 添字がラベル（変数ではない）ならローマン体。$T_{\mathrm{max}}$

### 記号

- マイナスは数学記号の $-$。ハイフン `-` で代用しない
- 掛け算は $\times$ または $\cdot$。`*` や中黒を使わない
- 不等号は $\le$, $\ge$, $\ne$。`<=`, `>=`, `!=` と書かない
- 省略記号は位置を使い分ける。$a_1, \dots, a_n$ と $a_1 + \cdots + a_n$

### 組み

- 分数は横棒で組む。入れ子や長い式を `a/b` で済ませない
- 根号は中身の高さに合わせ、どこまでが根号の下かを見て分かるようにする
- **括弧は中身の高さに合わせる。** 分数や総和を囲む括弧が本文サイズのままになっているのは組み違いである
- 総和・積・積分の上下限は、別行立てでは上下、インラインでは右肩に置く
- 行列は行と列が揃うように組み、括弧は全体の高さに合わせる

### 配置

- 独立した式は**別行立て**にし、前後にアキを取る
- 本文から参照する式には番号を振る。参照しない式には振らない
- 別行立ての式も文の一部である。式の後の句点や読点を落とさない
- 複数行の式は**等号の位置を揃える**
- インラインの式で行間が乱れるなら、別行立てにする

## 実現手段

上から順に検討する。

1. **TeX / LaTeX そのもの**が使えるなら使う
2. **KaTeX / MathJax** を使う。外部リソースを読めない環境では、インラインして同封する
3. **MathML** で組む。現行ブラウザは標準で描画でき、外部リソースが要らない
4. 図の中の式は **SVG** で、ベースラインと字形を保って置く

**本文フォントの文字並びで代用しない。** 手段がないのではなく、選ばなかっただけであることがほとんどである。

Markdown では `$...$` / `$$...$$` を使う。レンダラが数式を解さないなら、その文書は 1ー4 のどれかに変える。

## 白黒印刷への配慮

印刷される文書では、添字・二重添字・根号の横棒がつぶれない太さを保つ。色でしか区別できない表記にしない。

## 例外

ユーザーが記法や形式を明示した場合は、その指定を優先する。

コード、コマンド、設定値、ログの引用は数式ではない。等幅フォントのままにする。
