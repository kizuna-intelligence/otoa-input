# Kizuna Intelligence Print Defaults

PDF または文書を印刷する場合、ユーザーから別指定がない限り次を使います。

- 用紙: A4
- 1枚あたり: 2ページ
- 両面印刷: 長辺とじ
- 拡大縮小: 用紙に合わせる

CUPS / `lp` では原則として次を指定します。

```sh
-o media=A4 -o PageSize=A4 -o number-up=2 -o sides=two-sided-long-edge -o fit-to-page
```

ユーザーが用紙、ページ数、片面・両面、とじ方向、倍率を明示した場合は、その指定を優先します。

## HTML 文書の低トナー配色

HTML 文書は、印刷時のトナー消費を抑えられる配色をデフォルトにします。

- 背景は白にし、黒・グレー・濃色の背景、面積の大きな塗り、灰色のカード、装飾的なベタ塗りは使いません。
- 黒は本文、必要な罫線、記号など読解に必要な箇所だけに使います。情報の階層は、塗りではなく余白、細い罫線、文字サイズ、文字の太さで表現します。
- 色を使う必要がある場合も、白黒印刷で意味が失われない構成にします。
- ユーザーが配色やデザインを明示した場合は、その指定を優先します。
# Task Addition Scope

新しいタスクを追加または指示する際は、ユーザーが指定した内容のみを扱います。指定範囲外の機能追加、リファクタリング、抽象化は行いません。依頼文は、意味を変えない範囲で簡潔に整理します。

ただし、追加実装、設計、または設計を含む実装をユーザーが明示的に依頼した場合は、その依頼範囲に含まれる作業を追加して構いません。
