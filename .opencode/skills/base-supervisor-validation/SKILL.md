name: base-supervisor-validation
description: Validate assigned work and report the supervisor's findings directly to the named requester Session.
---

Read the requested artifact and repository evidence, run appropriate checks,
and make the validation judgment yourself. Report it as ordinary prompt text
to the exact requester Session named in the assignment when a report is
needed. Do not infer a recipient and do not use result, delivery, rollout,
WorkRun, or WorkEdge APIs.
