# Base Browser And Mobile Self-Testing

- Exercise affected browser workflows with available automation and inspect console or network failures when relevant.
- Use the repository-required real-device or simulator workflow for smartphone display, touch, or mobile Safari verification.
- Do not treat desktop responsive emulation as equivalent when simulator or device evidence is required.
- Report the exact missing browser, simulator, credential, network, or permission capability instead of silently skipping a required test.
